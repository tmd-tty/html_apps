# HTML Studio

ローカルフォルダの HTML を直接編集するエディタです。`html-studio.html` を Chrome または Edge で開くだけで使えます(Windows / Mac)。インストール、ビルド、サーバーはいずれも不要です。

Firefox と Safari はフォルダの読み書きに必要な File System Access API に対応していないため、使えません。

## できること

- フォルダのツリー表示、新規作成、名前の変更、複製、削除、ドラッグでの移動
- タブでの編集、行番号、リアルタイムプレビュー、閲覧モード、ダーク / ライト切り替え
- 閉じタグの自動補完、字下げを保った改行、HTML 整形、コメントの切り替え
- 太字、リンク、画像、テーブルの挿入、全文検索
- クリップボードの画像を `images` フォルダへ保存して `<img>` を挿入
- PDF 出力

ショートカットの一覧は、ヘルプボタンから確認できます。

## プレビューの制限

プレビューは安全のため、次のように動作します。プレビューの上に、対象になった件数を表示します。

- JavaScript は実行しません
- 外部の CSS、画像、フォント、動画、音声は読み込みません。ローカルの CSS と画像は読み込みます
- `<iframe>`、`<object>`、`<embed>` は表示しません
- 外部リンクは開けません。フォームは送信されません

そのため、JavaScript で画面を作るページや外部 CSS に頼るページは、プレビューと実際の表示が異なります。CSS は Shadow DOM の中に閉じ込めているので、アプリの画面には影響しません。

## 通信について

起動時に、DOMPurify の JavaScript を CDN(jsDelivr)から読み込みます。これ以外の通信はせず、編集中のファイルは外部へ送信しません。CSP で読み込める URL を1ファイルに限定し、バージョン固定と SRI で内容を検証しています。CDN に接続できないときは、原因を画面に表示します。

## PDF 出力

各ページを A4 240dpi 相当の画像にして PDF を生成します。そのため PDF 内の文字は選択や検索ができません。
