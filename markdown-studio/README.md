# Markdown Studio

ローカルフォルダのファイルを直接編集する Markdown エディタです。`markdown-studio.html` を Chrome または Edge で開くだけで使えます(Windows / Mac)。インストール、ビルド、サーバーはいずれも不要です。

Firefox と Safari はフォルダの読み書きに必要な File System Access API に対応していないため、使えません。

## エディタ

インデントはスペース4文字です。長い行は折り返さず、横スクロールで表示します。

表示は、エディタとプレビューを並べる分割表示のほか、プレビューだけを横幅いっぱいに表示する閲覧モード(`Ctrl+E`、Mac は `⌘E`)と、エディタだけを表示する編集のみ表示(`Ctrl+Shift+E`、Mac は `⌘⇧E`)を切り替えられます。

表の中で Enter を押すと行を追加し、その表を整形します。整形は手動の「テーブル整形」と同じで、全角・半角の幅をそろえます。

チェックボックスは、ボタンか `Alt+X`(Mac は `⌥X`)で付け外しできます。プレビューのチェックボックスをクリックすると、本文の `[ ]` と `[x]` も書き換わります。プレビューと本文の対応が取れないとき(本文に HTML のチェックボックスがある場合など)は、プレビューからは切り替えられません。

## 通信について

起動時に、下記のライブラリの JavaScript を CDN(jsDelivr)から読み込みます。docx だけは Word 出力を押したときに読み込みます。これと、クリックした外部リンクを開くこと以外の通信はせず、編集中の文書やファイルは外部へ送信しません。

- CSP で読み込める URL を4ファイルに限定し、`fetch` などによる送信は遮断しています
- バージョンを固定し、SRI でファイルの内容を検証しています。内容が異なるファイルは実行されません
- CDN に接続できないときは、原因を画面に表示します。一度読み込むとブラウザのキャッシュが使われますが、オフラインでの動作は保証しません

Markdown に外部の画像やリンクを書いても、それだけでは通信は発生しません。プレビューでは、外部画像は URL を示す枠で表示します。

外部リンクは、クリックしたときだけ新しいタブで開きます。開けるのは `http`、`https`、`mailto` です。開いたページには参照元を送りません。

## PDF 出力

各ページを A4 240dpi 相当の画像にして PDF を生成します。そのため PDF 内の文字は選択や検索ができません。

## Word 出力

「Word」ボタンで `.docx` を出力します。Markdown の構文から組み立てるので、見出しは見出しスタイル、リストは自動番号、表は Word の表になり、Word 上で編集できます。

- 用紙は A4 で、配色は画面のテーマにかかわらずライト固定です
- 表の行は分割せず、ページをまたぐときは見出し行を繰り返します
- Mermaid の図と画像は画像として埋め込みます。外部画像は読み込まず、URL の文字列を残します
- 外部リンクは Word 上で開けるリンクになります。内部リンクは文字だけ残します
