# Markdown Studio

ローカルフォルダのファイルを直接編集する Markdown エディタです。`markdown-studio.html` を Chrome または Edge で開くだけで使えます(Windows / Mac)。インストール、ビルド、サーバーはいずれも不要です。

Firefox と Safari はフォルダの読み書きに必要な File System Access API に対応していないため、使えません。

## 通信について

起動時に、下記のライブラリの JavaScript を CDN(jsDelivr)から読み込みます。これ以外の通信はせず、編集中の文書やファイルは外部へ送信しません。

- CSP で読み込める URL を4ファイルに限定し、`fetch` などによる送信は遮断しています
- バージョンを固定し、SRI でファイルの内容を検証しています。内容が異なるファイルは実行されません
- CDN に接続できないときは、原因を画面に表示します。一度読み込むとブラウザのキャッシュが使われますが、オフラインでの動作は保証しません

Markdown に外部の画像やリンクを書いても通信は発生しません。プレビューでは、外部画像は URL を示す枠で表示し、外部リンクは開けないようにしています。

## PDF 出力

各ページを A4 240dpi 相当の画像にして PDF を生成します。そのため PDF 内の文字は選択や検索ができません。
