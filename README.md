# html_apps

HTMLファイルを保存するだけで使えるブラウザアプリの置き場です。ビルドもサーバーも不要で、開けばそのまま動きます。

- 1アプリにつき1フォルダを作り、その中に1つの HTML ファイルを置く
- 外部サービスに頼らず、自作の CSS と JavaScript は HTML の中に書く
- アウトバウンド通信はしない。例外はライブラリの JavaScript を CDN から読み込むことだけ(詳細は `CLAUDE.md`)

## アプリ一覧

- [Markdown Studio](markdown-studio/README.md): ローカルフォルダを直接編集する Markdown エディタ
