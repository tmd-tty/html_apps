# Diagram Studio

フローチャート、システム構成図、自由な図やメモを描く作図ツールです。`diagram-studio.html` をブラウザ(Chrome または Edge)で開くだけで使えます。ライブラリを使わずに作っており、通信は一切しません。

## ファイル

- 「フォルダを開く」で作業フォルダを選び、左のエクスプローラーで図を開きます。複数の図をタブで切り替えられます
- 図はこのツール専用の JSON 形式で、拡張子は `.diagram.json` です。draw.io のファイルは開けません
- エクスプローラーの右クリックで、新しい図、新規フォルダ、名前の変更、複製、削除ができます。ドラッグでフォルダ間を移動できます
- 新しい図の名前は `YYYYMMDD_.diagram.json` が初期値です
- `Ctrl+S`(Mac は `⌘S`)で保存します。未保存のタブには丸印が付き、閉じるときに確認します

## 図形

- 左の一覧から図形をクリックすると画面の中央に、ドラッグすると好きな位置に追加します
- 基本: 四角、角丸、楕円、ひし形(判断)、平行四辺形(入出力)、データベース、書類、付箋、文字
- 構成: サーバー、クラウド、利用者、PC、スマートフォン、ストレージ、インターネット、データベース、グループの枠
- 枠を動かすと、枠の中に収まっている図形も一緒に動きます。枠は常に線や図形の奥に描きます
- 選んだ図形は、四隅と辺のつまみで大きさを変えられます
- 移動と大きさの変更はグリッドに合わせます。ツールバーのボタンで切り替えられ、`Alt` を押している間は一時的に解除します

## 線

- 図形にカーソルを合わせると、上下左右に点が出ます。点から別の図形へドラッグすると、矢印の線でつながります
- 線は図形を動かしても追従します。図形を消すと、つながっている線も消えます
- 線を選ぶと、色、経路(直角 / 直線)、矢印(終点 / 両端 / なし)、太さ、破線を変えられます。ダブルクリックでラベルを付けられます

## やりとりするデータ

構成図で、ノード間でやりとりするデータを線の上に表示できます。

- 線を選び、右の書式パネルの「ラベル」に経路や方式(HTTPS、API、バッチなど)を入力します
- 「+ データを追加」でデータ名を入力し、向き(例: `利用者 → Web サーバー`)を選びます。双方向のやりとりは、向きごとに1件ずつ追加します
- 線の中ほどの札に、ラベルと、向きの矢印付きのデータ名を一覧で表示します。矢印は線の向きに合わせて `→ ←` または `↓ ↑` になります
- データ名を空にするか `×` を押すと削除します。SVG / PNG の書き出しにも含まれます

## 文字

- 図形や線をダブルクリックするか、選んで `Enter` を押すと文字を編集できます。`Ctrl+Enter` か枠の外のクリックで確定し、`Esc` で取り消します
- 何もない所をダブルクリックすると、その場所に文字を置きます
- 文字は図形の幅に合わせて折り返します。書式パネルで色、大きさ、太字を変えられます

## 操作

| 操作 | キー |
| --- | --- |
| 元に戻す / やり直す | `Ctrl+Z` / `Ctrl+Shift+Z`(`Ctrl+Y`) |
| コピー / 切り取り / 貼り付け / 複製 | `Ctrl+C` / `Ctrl+X` / `Ctrl+V` / `Ctrl+D` |
| すべて選択 | `Ctrl+A` |
| 複数選択 | `Shift+クリック`、何もない所からドラッグ |
| 少しずつ動かす | 矢印キー(`Shift` で10) |
| 画面の移動 | スクロール、`Space` を押しながらドラッグ、ホイールボタンでドラッグ |
| 拡大・縮小 / 全体表示 | `Ctrl+スクロール`、`Ctrl+=` `Ctrl+-` / `Ctrl+0` |
| 最前面へ / 最背面へ | `Ctrl+Shift+]` / `Ctrl+Shift+[` |

Mac では `Ctrl` の代わりに `⌘` を使います。`?` ボタンで一覧を表示できます。

## 書き出し

ツールバーの「SVG」「PNG」で、図と同じフォルダに同じ名前の `.svg` / `.png` を書き出します。余白を付けて図の範囲だけを切り出し、PNG は2倍の解像度にします。
