# Org Chart Editor

プロジェクトやチームの体制図を作成するツールです。`org-chart-editor.html` をブラウザで開くだけで使えます。PowerPoint 出力のときを除いて通信はしません。

## 使い方

- 「ノード追加」で最上位のノードを追加します。カードにカーソルを合わせて `+` を押すと、その下にノードを追加します
- 各ノードにはグループ名、リーダー、メンバー、備考を登録できます。リーダーとメンバーは1行に1人ずつ入力します(`、` でも区切れます)
- カードには、名前の後に `★` を付けてリーダーを先に表示し、続けてメンバーと備考を表示します
- グループ名をクリックすると編集できます
- カードを別のカードへドラッグすると、その下へ移動します。編集画面の「親ノード」でも移動できます
- `◀` `▶` で同じ階層の順番を変えられます
- 削除すると配下のノードも一緒に削除します

## 元に戻す・やり直す

追加、編集、削除、移動、並べ替えは、`Ctrl+Z`(Mac は `⌘Z`)で元に戻し、`Ctrl+Shift+Z` か `Ctrl+Y`(Mac は `⌘⇧Z`)でやり直せます。ツールバーの `↶` `↷` でも操作できます。最大100回まで戻せます。

## 全体表示

「全体表示」を押すと、体制図全体が画面に収まるよう縮小して表示します。もう一度押すと元の大きさに戻ります。縮小したままでも、編集やドラッグができます。

## 未保存の内容の自動退避

保存していない内容は、ブラウザ内に自動で控えます。保存せずにブラウザを閉じたり、ブラウザが異常終了したりした場合は、次に開いたときに復元するかを確認します。控えは外部へ送信せず、保存すると消えます。

## 保存

体制図は JSON ファイルで保存します。ブラウザ内の控えは異常終了に備えた非常用なので、作業の終わりに必ずファイルへ保存してください。Chrome と Edge は開いたファイルをそのまま上書きできます。Firefox と Safari は同じ名前で再ダウンロードします。

```json
{
  "app": "Org Chart Editor",
  "version": 1,
  "nodes": [
    { "group": "プロジェクト", "leaders": ["山田"], "members": ["佐藤", "鈴木"], "note": "週次で進捗を報告", "color": "blue", "children": [] }
  ]
}
```

`note` と `color` は省略できます。`color` には`red`、`orange`、`yellow`、`green`、`teal`、`blue`、`indigo`、`purple`、`pink`、`gray` を指定できます。

## PowerPoint 出力

「PowerPoint出力」で、体制図を 16:9 の `.pptx` に書き出します。画像ではなく図形として出力するので、グループ名、本文、接続線を PowerPoint 上で個別に編集できます。

- 配置は画面と同じです。配色は画面のテーマにかかわらずライト固定です
- 1枚で読める大きさに収まらないときは、上の階層と各グループの配下に分けて複数のスライドにします
- 接続線は通常の線です。カードを動かしても線は追従しません

ボタンを押したときだけ、jsDelivr から PptxGenJS 4.0.1(MIT)の JavaScript を読み込みます。CSP でこの URL だけを許可し、SRI で内容を検証しています。体制図のデータは送信しません。オフラインでは出力できませんが、それ以外の機能は使えます。
