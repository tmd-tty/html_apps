# Org Chart Editor

プロジェクトやチームの体制図を作成するツールです。`org-chart-editor.html` をブラウザで開くだけで使えます。PowerPoint 出力のときを除いて通信はしません。

## 使い方

- 「ノード追加」で最上位のノードを追加します。カードにカーソルを合わせて `+` を押すと、その下にノードを追加します
- 各ノードにはグループ名、リーダー、メンバーを登録できます。リーダーとメンバーは1行に1人ずつ入力します(`、` でも区切れます)
- グループ名をクリックすると編集できます
- カードを別のカードへドラッグすると、その下へ移動します。編集画面の「親ノード」でも移動できます
- `◀` `▶` で同じ階層の順番を変えられます
- 削除すると配下のノードも一緒に削除します

## 保存

体制図は JSON ファイルで保存します。ブラウザ内には保存しないので、作業の終わりに必ずファイルへ保存してください。Chrome と Edge は開いたファイルをそのまま上書きできます。Firefox と Safari は同じ名前で再ダウンロードします。

```json
{
  "app": "Org Chart Editor",
  "version": 1,
  "nodes": [
    { "group": "プロジェクト", "leaders": ["山田"], "members": ["佐藤", "鈴木"], "color": "blue", "children": [] }
  ]
}
```

`color` は省略でき、`red`、`orange`、`yellow`、`green`、`teal`、`blue`、`indigo`、`purple`、`pink`、`gray` を指定できます。

## PowerPoint 出力

「PowerPoint出力」で、体制図を 16:9 の `.pptx` に書き出します。画像ではなく図形として出力するので、グループ名、本文、接続線を PowerPoint 上で個別に編集できます。

- 配置は画面と同じです。配色は画面のテーマにかかわらずライト固定です
- 1枚で読める大きさに収まらないときは、上の階層と各グループの配下に分けて複数のスライドにします
- 接続線は通常の線です。カードを動かしても線は追従しません

ボタンを押したときだけ、jsDelivr から PptxGenJS 4.0.1(MIT)の JavaScript を読み込みます。CSP でこの URL だけを許可し、SRI で内容を検証しています。体制図のデータは送信しません。オフラインでは出力できませんが、それ以外の機能は使えます。
