# Macro Schedule Editor

プロジェクトの大日程を月単位で管理するガントチャートです。`macro-schedule-editor.html` をブラウザで開くだけで使えます。PowerPoint 出力のときを除いて通信はしません。

## マイルストーン

「マイルストーン追加」から、期間を持たない日付1点の項目を追加できます。チャートには ◆ と日付、名前を表示します。グループ分け、並べ替え、強調表示はタスクと同じように使えます。◆ をドラッグすると日単位で移動できます。

## 期間の変更

バーをドラッグすると月単位で期間を変えられます。中央をドラッグすると期間ごと移動し、左右の端をドラッグすると開始月や終了月だけが変わります。ドラッグ中に Esc を押すと取り消せます。バーをクリックすると編集画面が開きます。

## 並べ替えとグループ

行にカーソルを合わせると表示される ▲▼ か、左の列のドラッグで順序を変えられます。

- タスクを別のグループの行やグループ見出しへドラッグすると、そのグループへ移動します
- グループ見出しをドラッグすると、グループごと移動します
- グループ見出しの名前をクリックすると、名前を一括で変更できます。既存のグループと同じ名前にすると、確認のうえ統合します

## PowerPoint 出力

「PowerPoint出力」で、ガントチャートを 16:9 の `.pptx` に書き出します。画像ではなく図形として出力するので、バー、◆、見出し、線などを PowerPoint 上で個別に編集できます。「選択」ウィンドウには `バー: 要件定義` のような名前で表示されます。

- 配色は画面のテーマにかかわらずライト固定です
- 1スライドに最大20行で、超えるとスライドを分けます。暦は常にスライドの幅に収めます
- 長いタスク名は枠に合わせて省略します。正式名は図形の名前に残ります

ボタンを押したときだけ、jsDelivr から PptxGenJS 4.0.1(MIT)の JavaScript を読み込みます。CSP でこの URL だけを許可し、SRI で内容を検証しています。スケジュールのデータは送信しません。オフラインでは出力できませんが、それ以外の機能は使えます。

## 保存

スケジュールは JSON ファイルで保存します。ブラウザ内には保存しないので、作業の終わりに必ずファイルへ保存してください。

| ブラウザ | 上書き保存 |
|:--|:--|
| Chrome / Edge | 開いたファイルをそのまま上書きする |
| Firefox / Safari | 同じ名前で再ダウンロードする。元のファイルは上書きされない |

## ファイル形式

```json
{
  "app": "Macro Schedule Editor",
  "version": 2,
  "tasks": [
    { "group": "企画フェーズ", "name": "要件定義", "start": "2026-04", "end": "2026-07", "highlight": false },
    { "type": "milestone", "group": "企画フェーズ", "name": "承認", "date": "2026-07-31", "highlight": true }
  ]
}
```

`group` は空文字でも構いません。`tasks` の並びが表示順になります。`version` が 1 のファイルも開けます。
